# Plan: Add "使用说明" (Usage Guide) Tab Page

## Overview
Add a new navigation item "使用说明" visible to all users, rendering the content from `使用说明.md` as a styled markdown page with a sidebar TOC (Table of Contents).

## Current State
- React 19 + TypeScript + Tailwind CSS + Radix UI
- No markdown rendering library installed
- Navigation defined in `src/components/layout/sidebar.tsx` (navItems for all users, adminItems for admin)
- Routes defined in `src/router.tsx`

## Implementation Steps

### Step 1: Install markdown dependencies
```bash
npm install react-markdown remark-gfm
```

### Step 2: Create markdown content file
Copy `使用说明.md` to `src/pages/usage-guide/content.md` (slightly simplified for web display - remove redundant sections like the full professional search expression details, keep the core workflow and module explanations).

### Step 3: Create the Usage Guide page
**File**: `src/pages/usage-guide/index.tsx`

Features:
- Import markdown content using Vite's `?raw` suffix
- Parse headings from markdown to build TOC
- Render markdown using `react-markdown` with `remark-gfm`
- Layout: left TOC sidebar (sticky, ~200px) + right content area
- TOC links scroll to corresponding headings with smooth scroll
- Current section highlighted in TOC based on scroll position (Intersection Observer)
- Style headings, lists, tables, code blocks to match the warm professional palette

### Step 4: Add route
**File**: `src/router.tsx`

Add route under the authenticated layout children:
```tsx
{ path: 'usage-guide', element: <UsageGuidePage /> },
```

### Step 5: Add sidebar navigation
**File**: `src/components/layout/sidebar.tsx`

Add to `navItems` array (visible to all users):
```tsx
{ to: '/usage-guide', label: '使用说明', icon: HelpCircle, roles: ['admin', 'user'] },
```

Import `HelpCircle` from `lucide-react`.
