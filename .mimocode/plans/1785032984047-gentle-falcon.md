# 登录页视频背景优化 + 全局配色调整

## 概述

将登录页从简单的卡片表单改为全屏视频背景 + 毛玻璃登录卡片的沉浸式设计，同时全局调整配色以匹配视频的暖色调插画风格。

## 修改范围

### 1. 全局配色调整 — `src/index.css`

**目标**：将 stone 色系调整为更贴合视频暖色调（米色/棕褐/大地色）的配色。

**Light 主题修改**：
```css
:root {
  --background: #f7f3eb;      /* 更暖的米色，匹配视频底色 */
  --foreground: #2c2416;      /* 深棕色，比 stone-900 更暖 */
  --card: #fffcf7;            /* 微暖白 */
  --card-foreground: #2c2416;
  --popover: #fffcf7;
  --popover-foreground: #2c2416;
  --primary: #6b4226;         /* 棕褐色主色，呼应视频中的赭石 */
  --primary-foreground: #fffcf7;
  --secondary: #f0ebe1;       /* 暖灰 */
  --secondary-foreground: #5c3d1e;
  --muted: #f0ebe1;
  --muted-foreground: #8a7a68; /* 暖灰文字 */
  --accent: #f0ebe1;
  --accent-foreground: #5c3d1e;
  --destructive: #9e2a2b;
  --destructive-foreground: #fffcf7;
  --border: #e0d8cc;          /* 暖色边框 */
  --input: #e0d8cc;

}
```

### 2. 登录页重构 — `src/pages/login/index.tsx`

完全重写登录页，实现：
- 全屏视频背景（z-0）
- 白色渐变遮罩保证可读性（z-1）
- 毛玻璃登录卡片（z-2）
- 移动端降级为静态图

```tsx
export default function LoginPage() {
  // ...状态逻辑保持不变...

  return (
    <div className="relative min-h-screen w-full overflow-hidden">
      {/* 视频背景 - 桌面端 */}
      <video
        autoPlay muted loop playsInline preload="metadata"
        className="hidden md:block absolute inset-0 w-full h-full object-cover z-0"
      >
        <source src="/backvideos.mp4" type="video/mp4" />
      </video>

      {/* 静态背景 - 移动端 */}
      <div
        className="block md:hidden absolute inset-0 z-0"
        style={{
          background: 'linear-gradient(135deg, #f7f3eb 0%, #e0d8cc 50%, #c4b8a8 100%)'
        }}
      />

      {/* 顶部白色渐变遮罩 */}
      <div
        className="absolute inset-x-0 top-0 h-[60vh] pointer-events-none z-[1]"
        style={{
          background: 'linear-gradient(180deg, rgba(247,243,235,0.95) 0%, rgba(247,243,235,0) 100%)'
        }}
      />

      {/* 内容区 */}
      <div className="relative z-[2] min-h-screen flex flex-col">
        {/* 导航栏 */}
        <nav className="flex items-center justify-between px-8 md:px-16 py-6">
          <span className="text-2xl font-bold text-[#6b4226]">CNKI</span>
          <Button variant="ghost" className="text-[#6b4226] text-sm">
            帮助中心
          </Button>
        </nav>

        {/* 登录卡片 */}
        <div className="flex-1 flex items-center justify-center px-4 pb-16">
          <Card className="w-full max-w-md bg-white/60 backdrop-blur-xl border-white/30 shadow-2xl">
            <CardHeader className="text-center">
              <CardTitle className="text-xl text-[#2c2416]">
                CNKI定题检索服务
              </CardTitle>
            </CardHeader>
            <CardContent>
              {/* 表单保持不变 */}
            </CardContent>
          </Card>
        </div>
      </div>
    </div>
  )
}
```
