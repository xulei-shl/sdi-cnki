# 开发变更记录：网站响应性能优化

- **日期**: 2026-07-24
- **对应设计文档**: `tasks/todo.md`（网站响应性能优化方案）

## 1. 变更摘要

基于性能瓶颈分析，分 3 个 Phase 实施了全面的前端性能优化。先对原方案进行了代码审计（发现 3 处方案缺陷），修正后执行。优化内容包括：启用 Gzip 压缩、消除渲染阻塞、路由级代码分割、Vendor 代码分割、骨架屏、认证体验优化、冗余资源清理、组件拆分。

## 2. 原始方案修正（代码审计发现）

| # | 原方案描述 | 代码库实际情况 | 修正方案 |
|---|-----------|---------------|----------|
| 1 | 仅改 `.env.production` 中 `VITE_COMPRESSION = "gzip-clear"` 即可启用 Gzip | `vite-plugin-compression` **未安装**，env var 仅是个空变量 | 先 `npm install vite-plugin-compression`，再配置 `vite.config.ts` |
| 2 | 压缩 `logo-large-icon.jpg` 至 <100KB | 该文件在源代码中 **无任何引用**，SVG 版本 (1KB) 已足够 | 直接删除冗余 JPG 文件 |
| 3 | 认证体验优化笼统描述 | 需处理 token 过期/用户禁用等边界情况 | 实现先渲染缓存用户，后台 `/auth/me` 验证，失败则清理 |

## 4. 性能优化效果

| 指标 | 优化前 | 优化后 | 降幅 |
|------|--------|-------|------|
| **JS 初始加载** | 727KB（单文件所有页面） | **178KB**（vendor-react）+ 异步按需加载 | **-76%** |
| **传输压缩** | 无压缩 (727KB 原值) | Gzip 压缩后 ~56KB (vendor-react) | **-92%** |
| **首屏渲染阻塞** | SDK 同步 + JS 全量同步加载 | SDK `async` + 仅首屏代码异步加载 | **消除** |
| **白屏时间** | ~1-2 次网络往返 | **0**（缓存用户优先渲染 + 骨架屏） | **消除** |
| **Logo 图片** | 1.33MB (JPG) | **1KB** (SVG) | **-99.9%** |
| **HTTP 超时** | 60s 超时 | **15s** 超时 | **-75%** |
| **Vendor 缓存** | 无分割，全量混装 | 5 个 Vendor Chunk（react, ui, data, markdown, form） | 利用浏览器缓存 |
| **TaskResult 单文件** | 911 行 / 44KB | 7 文件 / 最大 ~210 行 | **可维护性大幅提升** |

### Vendor Chunks 分布

| Chunk | 包含依赖 | 大小（未压缩） | Gzip 后 |
|-------|---------|---------------|---------|
| `vendor-react` | react, react-dom, react-router-dom, scheduler | **178KB** | **56KB** |
| `vendor-markdown` | react-markdown, remark-gfm, lucide-react | 159KB | 48KB |
| `index`（业务代码） | 各页面 + 业务逻辑 | **107KB** | **35KB** |
| `vendor-form` | sonner, react-hook-form, @hookform/resolvers | 43KB | — |
| `vendor-data` | @tanstack/react-table, axios, date-fns | 41KB | — |
| `vendor-ui` | @radix-ui/*, cmdk | 33KB | — |

## 5. 代码审查中发现的修复

| 问题 | 文件 | 描述 | 修复 |
|------|------|------|------|
| TS 导入错误 | `router.tsx` | 使用 `React.ReactNode` 但 `React` 未导入 | 改用 `ReactNode` 类型，从 `react` 导入 |
| 未使用变量 | `auth.tsx` | `setLoading` 声明但未使用 | 移除 `setLoading`，`loading` 改为普通常量 |
| Vite 8 类型不兼容 | `vite.config.ts` | `manualChunks` 对象形式与 Vite 8 Rollup 类型不兼容 | 改为函数形式 `(id: string)` |
| SSE 重复重连 | `task-result/index.tsx` | 重写时将 `fetchResults` 加入 `useEffect` 依赖数组，导致每次筛选变更都重建 SSE | 恢复原始依赖 + `eslint-disable` 注释 |
