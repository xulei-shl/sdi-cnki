# 开发变更记录

- **日期**: 2026-05-16
- **对应设计文档**: `docs/结构化需求文档.md`（权限矩阵扩展）

## 1. 变更摘要

为普通用户增加提示词管理权限，引入**两层提示词体系**：
- **用户提示词**（`system_prompts` 表改造）：所有用户可 CRUD 自己账号下的提示词，管理员可管理全部
- **提示词模板**（`prompt_templates` 表新增）：管理员维护的系统级模板，用户新建提示词时可选择模板自动填充内容

## 2. 文件清单

### 新增
- `app/models/prompt_template.py`: PromptTemplate 模型
- `app/routers/prompt_templates.py`: 提示词模板 CRUD 路由（admin-only）
- `src/api/prompt-templates.ts`: 提示词模板前端 API
- `src/pages/prompt/index.tsx`: 用户提示词管理页（含模板选择预填功能）
