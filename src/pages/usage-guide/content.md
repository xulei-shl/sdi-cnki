# 学术文献定题检索系统使用说明

## 一、系统概述

围绕 **中国知网（CNKI）** 提供自动化检索、智能评估、人工审核、批量下载与结果导出的一站式工作流。

> 当前主要应用场景是汽车图书馆 CNKI 主题数据检索服务。

普通用户主要使用以下三个核心模块：

| 模块 | 作用 |
|------|------|
| **提示词** | 编写和管理用于大模型（LLM）评估文献相关性的提示词，是判断文献是否命中的评判标准 |
| **任务模板** | 配置检索条件（检索词、时间范围、核心期刊等）并绑定评估提示词，是可重复使用的检索策略模板 |
| **任务实例** | 模板的一次实际运行记录，展示完整的检索、分析、审核、下载进度与结果数据 |

---

## 二、完整工作流概览

```
创建/选择提示词 → 配置任务模板 → 运行模板 → CNKI 自动检索
    → LLM 智能分析 → 人工审核 → PDF 下载 → 导出结果
```

每个关键步骤完成后，系统会通过**企业微信**推送通知。

---

## 三、模块详细说明

### 3.1 提示词

提示词是告诉大模型"什么样的文献算相关"的评判标准。系统内置了可选模板，也可以自行创建。

**操作路径**：左侧导航 → 提示词

**功能**：
- **新建提示词**：点击"新建提示词"，可选择系统提供的**提示模板**作为起点，在模板基础上手动修改；也可直接编写
- **AI 辅助生成**：编辑时可用页面右下角的 **AI 助手**（HiAgent）帮助生成或优化提示词内容
- **模板类型**：新建时可选择「普通模板」或「兜底分析模板」。
  - **普通模板**（默认）：用于任务模板中绑定，作为指定的评判标准。
  - **兜底分析模板**：由管理员在「提示词模板」页面配置，全局生效。当任意用户的任务实例运行时未绑定评估提示词，系统将自动加载该模板进行分析。可在内容中使用 `{{search_conditions}}` 占位符，系统会自动替换为本次检索条件（检索词、时间范围等）；若不使用占位符，检索条件将追加在末尾。系统全局仅允许存在一个兜底模板。

### 3.2 任务模板

任务模板（元任务）定义了"搜什么、用什么标准评估"。

**操作路径**：左侧导航 → 任务模板

**创建模板时需要填写**：

| 配置项 | 说明 |
|--------|------|
| **任务名称** | 给这套检索策略起一个便于识别的名称 |
| **检索模式** | 选择 **普通检索模式** 或 **专业检索模式**（详见下方说明） |
| **检索条件** | 根据所选模式填写普通关键词，或填写专业检索表达式对应的关键词组 |
| **检索时间范围** | 起始年份 / 结束年份 / 更新日期范围（二者互斥） |
| **核心期刊** | 是否仅限核心来源 |
| **同义词扩展** | 是否开启知网同义词扩展 |
| **包含无全文文献** | 是否包含无全文文献（默认仅看有全文） |
| **最大导出量** | 单次检索最多导出的文献数，可选值：50/100/150/200/250/300/350/400/450/500 |
| **LLM 配置** | 用于相关性评估的大模型，可配置多个并按优先级排序 |
| **评估提示词** | 选择已有的提示词作为本次检索的评判标准 |
| **去重范围** | 可选择其他任务模板作为参考去重范围，避免重复采集历史已入库文献 |

### 3.3 两种检索模式

系统支持两种 CNKI 检索模式：

| 模式 | 适用场景 | 执行方式 |
|------|----------|----------|
| **普通检索模式** | 关键词较少、希望快速覆盖主题的常规检索 | 每个检索词单独执行一次高级检索，最后合并结果并自动去重 |
| **专业检索模式** | 需要明确布尔逻辑、限定主题组合、作者或基金范围的精细化检索 | 切换到知网"专业检索"页，只执行 1 次完整布尔表达式检索 |

#### 如何选择

| 你的需求 | 建议模式 |
|----------|----------|
| 先尽可能多找，再交给 AI 和人工筛选 | **普通检索模式** |
| 需要明确"主题A + 主题B"的交叉关系 | **专业检索模式** |
| 需要按作者限定 | **专业检索模式** |
| 需要按基金限定 | **专业检索模式** |
| 只会输入几个普通关键词，追求操作简单 | **普通检索模式** |

**经验建议**：
- 不确定时，先用**普通检索模式**做一轮广覆盖
- 结果过多、噪音较大时，再改为**专业检索模式**做精筛
- 专业检索条件不宜一次写得过满，否则可能导致结果过少

### 3.4 两种运行模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **直接运行** | 自动创建任务实例，立即开始 CNKI 检索 | 模板参数已确认，想一键执行 |
| **确认后运行** | 只先创建任务实例（状态为待处理），人工可编辑参数后再手动触发运行 | 想在运行前调整检索条件，或通过 Excel 导入自有数据 |

### 3.5 去重范围配置

可选择其他任务模板作为参考去重范围。配置后，本次检索结果不仅与当前模板的历史数据去重，还会与所选参考模板的所有历史数据比对去重。

**适用场景**：
- 多个模板检索相近主题时，避免重复采集
- 需要跨任务追踪同一领域的增量文献

## 四、任务实例流程

任务实例是整个检索任务的运行单元，展示从检索到导出的完整进度。

**操作路径**：左侧导航 → 任务实例

### 4.1 检索与去重（自动）

- 系统使用浏览器自动化技术，自动在知网完成搜索并导出结果
- 自动对检索结果进行去重（基于标题 + 期刊 + 年份）
- 完成后自动进入 LLM 分析阶段
- **企业微信通知**：检索完成时推送通知，包含检索数量、有效数据数、重复数

### 4.2 LLM 分析（自动）

- 系统将每条文献的标题、关键词、摘要提交给配置的大模型进行评估
- **提示词加载顺序**：分析时优先使用任务绑定的评估提示词；若未绑定，则自动加载系统中标记为「兜底分析」的已启用模板（并拼接本次检索条件）；若仍不存在，使用系统内置的默认提示词
- 每批处理 5 条，支持多个 LLM 配置自动切换（主配置失败后自动换备用）
- 分析结果包含：**是否相关、相关度评分（0-10）、相关度等级（高/中/低/不相关）、推理说明**
- **重试**：分析失败的文献会标记错误信息，可点击"重试"按钮逐条重新分析
- **企业微信通知**：分析完成时推送统计结果

### 4.3 人工审核

LLM 分析完成后，需要人工确认每条/批量文献是否通过。

**操作路径**：任务实例列表 → 点击某实例 → 进入结果页面

**功能**：
- **筛选**：按分析状态、分析结果、评分阈值、审核状态等过滤
- **批量操作**：选中多条文献，一键批量通过或拒绝
- **逐条操作**：点击某条文献查看详情，在详情面板中通过或拒绝
- **逐条浏览**：支持上一条/下一条导航，边看边审

**重要**：只有标记为"通过"的文献才会进入后续的 PDF 下载环节。

### 4.4 PDF 下载

人工审核通过后，点击 **PDF 下载** 按钮开始批量下载。

- 系统依次从多个来源尝试获取 PDF（哲社科 → 万方 → CNKI）
- **下载失败处理**：下载失败的文献会标记错误，可逐条点击"重试"重新下载
- **企业微信通知**：下载完成时推送统计

### 4.5 结果导出

所有流程完成后，可以打包导出最终结果。

- 点击"导出"按钮，系统异步打包 ZIP 文件
- 导出包包含：
  - `results.xlsx`：完整元数据 + LLM 分析评分
  - `analysis_results.xlsx`：LLM 分析原始结果明细
  - `metadata.json`：实例配置与统计摘要
  - `references.enw`：参考文献列表，可导入 Zotero 等文献管理软件
  - `pdfs/`：已下载的 PDF 文件

- 打包完成后自动触发下载，导出链接 24 小时内有效

### 4.6 删除任务实例

如果不再需要某个任务实例及其所有数据，可以直接删除。

**操作路径**：任务实例列表 → 点击实例右侧的"删除"按钮

**级联删除内容**：
- 该实例下的全部检索结果（文章数据）
- LLM 分析评分记录
- PDF 下载记录及已下载的 PDF 文件（如果该 PDF 还被其他实例引用，仅解除引用，不删除文件）
- 关联的导出文件
- 队列中等待执行的任务

**注意**：删除操作不可恢复。任一状态（含运行中）的实例均可删除，强烈建议确认实例已不再需要后再操作。

## 五、企业微信通知

在系统配置中设置企业微信 Webhook URL 后，以下环节会自动推送通知：

| 环节 | 通知内容 |
|------|----------|
| 检索完成 | 检索总数、有效数据数、重复数、耗时 |
| 分析完成 | 分析总数、通过数、拒绝数、失败数 |
| 下载完成 | 下载成功数、失败数 |

**配置位置**：左侧导航 → 通知设置

如需获取 Webhook URL，请参考企业微信文档创建自定义机器人并获取对应 webhook 地址。

## 六、常见操作速查

| 我想做什么 | 怎么做 |
|------------|--------|
| 创建一套检索策略 | 提示词 → 新建提示词（或用模板/AI 辅助）→ 任务模板 → 新建模板（绑定提示词和 LLM） |
| 马上执行一次检索 | 任务模板 → 运行 → 选择"直接运行" |
| 先看看参数再运行 | 任务模板 → 运行 → 选择"确认后运行" → 在任务实例中编辑参数后再运行 |
| 导入我从知网手动导出的文献 | 任务实例 → 选中的实例 → 导入 Excel |
| 查看分析结果 | 任务实例 → 点击实例编号 → 进入结果页面 |
| 批量审核文献 | 结果页面 → 筛选 → 勾选多条 → 批量通过/拒绝 |
| 下载已通过文献的 PDF | 结果页面 → 点击"PDF 下载"按钮 |
| 下载单篇失败的 PDF | 结果页面 → 点击该条的"重试" |
| 打包导出最终结果 | 任务实例详情 → 点击"导出" |
| 删除任务模板（含所有执行记录） | 任务模板列表 → 点击"删除" |
| 删除单个任务实例（含结果/分析/下载） | 任务实例列表 → 点击"删除" |
